# Competitive Programming

Soluções de questões do ICPC resolvidas em upsolving, em C++.

## Estrutura

| Caminho | Conteúdo |
| --- | --- |
| `macros.cpp` | Template com as macros usadas nas soluções |
| `icpc-2026-brazil-subregional/` | Questões C, E, F e M da Subregional Brasil 2026 da Maratona SBC de Programação |

## Como rodar

```bash
g++ -std=c++17 -O2 icpc-2026-brazil-subregional/e.cpp -o a.out
./a.out < a.in
```
